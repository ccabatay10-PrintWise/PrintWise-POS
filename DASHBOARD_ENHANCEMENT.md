# PrintWise Dashboard Enhancement

Enhanced dashboard includes:
- Dynamic greeting for the logged-in user
- Total completed sales across available order records
- Today / 7 Days / 30 Days sales filters
- Sales trend visualization
- Completed, pending, processing, and other order counts
- Average completed order value
- Recent transactions
- Inventory low-stock alerts
- Quick action cards
- Admin-only Staff Management section
- Staff users no longer see the Staff Management panel

## Updated files
- `app/dashboard/page.tsx`
- `app/dashboard/dashboard.css`

No database schema changes are required for this dashboard update.
